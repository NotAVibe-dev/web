Brand

The mark is a logical NOT — ¬ — "not a vibe" said in one glyph. This page is the canonical copy of the mark, the wordmark, the colour and the type, plus the rules for using them. If you need the logo, take it from here rather than from a screenshot, a deck or another repository.

1.The mark

A single stroke that turns a corner. It carries the product's whole argument — that a package looking popular is not the same as a package being alive — without a word of copy. Drawn on a 24-unit grid, stroke 2.5, round caps and joins.

On darkThe default. Accent green on the near-black canvas.

On lightThe same green, unchanged. It holds at this weight.

On accentUse the mono cut, which inherits currentColor.

2.The lockup

Mark, then wordmark. "nota" takes the ink, "vibe" the muted step — the green negation plus a dimmed "vibe" is what makes the lockup read as a sentence rather than as decoration. Inter SemiBold, tracking −0.4, outlined to paths — the files carry the real glyph contours, so they render identically everywhere and depend on no font being installed.

On darklogo-lockup.svg — ink #ffffff, muted #b2b6bd.

On lightlogo-lockup-light.svg — ink #0b0d10, muted #5e646c.

Two files, one per surface, with the inks baked in. A single file inheriting currentColor looks tidier and does not work: an SVG loaded through an <img> tag is an isolated document and cannot see the host page's colour, so it renders black on black wherever it is used as an image. Both variants use the site's own ink tokens, so the lockup cannot drift from the chrome beside it.

3.Colour

#00ca8e is the only brand colour. It carries the mark, primary actions and live status — nothing else. A second accent is the fastest way to stop looking like one product.

Accent#00ca8evolt-emerald · mark, primary CTA, live status
Canvas#000000volt-void · page, hero, footer
Icon tile#0C0F0Efavicon ground only — not a site token
Ink#ffffffvolt-white · headings, "nota"
Ink muted#b2b6bdvolt-text-500 · body, "vibe"
On accent#04120dvolt-on-emerald · ink on emerald buttons

Never put white on the accent — it measures 2.13:1 and fails. #04120d on #00ca8e is 8.96:1.

4.Type

FaceWhere it is used
InterHeadlines, body, buttons, and the wordmark. SemiBold 600 in the lockup, 700 for display.
IBM Plex MonoEvery number, command, identifier, timestamp and status value — anything a machine produced or a person could type.

Two faces, and only two. The wordmark is the same Inter, outlined into the lockup files, so it is identical in a browser, a design tool and a PDF without anyone installing anything — and identical to the wordmark the site renders as live text beside it.

5.Assets

These are the canonical files. Everything else — the icon rasters, the share card — is derived from them.

FileWhat it is
logo-mark.svg The mark. 24-grid, stroke 2.5, accent green, transparent ground — place it on a dark surface.
logo-mark-mono.svg The mark with no colour literal at all — inherits currentColor. Use at small sizes, in print, and on accent surfaces.
logo-lockup.svg Mark plus wordmark, for dark surfaces.
logo-lockup-light.svg The same lockup, for light surfaces.
favicon.svg The mark on its tile, 32-grid. Its stroke is 4/32 rather than the full-size 2.5/24 — the thinner weight disappears at 16px. Every raster icon size is rendered from this file.
favicon.ico apple-touch-icon.png Derived icon rasters, at the sizes browsers ask for.
og.png og.svg Share card, 1200×630. The PNG is what ships — most scrapers will not render an SVG.

6.Using it

Do

  • Reserve #00ca8e for the mark, one primary action, and live status.
  • Use the mono cut on accent or unknown grounds, and set color on the parent.
  • Give the mark clear space of at least its own stroke width on every side.
  • Set numbers and commands in IBM Plex Mono, even inside prose.
  • Derive rasters from the SVG rather than resizing a PNG.

Don't

  • Don't recolour the mark. It is accent green, or it inherits — never a third hue.
  • Don't put white ink on the accent. It fails contrast.
  • Don't add a second accent to a marketing surface.
  • Don't stretch, rotate, outline or add effects to the mark.
  • Don't rebuild the glyph by hand — the path is in section 7.

7.Deriving assets

The glyph is one path. If you are vendoring the mark into another repository, copy this rather than re-drawing it, and record where it came from. 

<path d="M4.5 9.5 H 18.5 V 16" stroke="currentColor" stroke-width="2.5"
      stroke-linecap="round" stroke-linejoin="round"/>

Rasterise with rsvg-convert (brew install librsvg):

rsvg-convert -w 180 -h 180 favicon.svg -o apple-touch-icon.png
rsvg-convert -w 32  -h 32  favicon.svg -o favicon-32.png

Two traps, both of which have already shipped bugs here. ImageMagick without librsvg silently drops the stroke — you get the tile and no mark, with no error. Headless Chrome composites element screenshots onto white, so rounded corners come out opaque instead of transparent. Use Chrome only for artwork containing webfont text, such as the share card.

And never write a CSS custom property into an SVG comment. A double hyphen makes the file malformed XML — browsers render it anyway, so it fails silently until something strict rejects it.
